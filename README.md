# ネオOMナビ（静的版）

GitHub Pagesで動く、サーバー不要のOMナビビューア＋日中入力ツール。

## 機能

- ダッシュボード / アンサーカード / 物件 / 工務店 / 商品 の一覧・検索・詳細（閲覧）
- 「今日の入力」: アンサーカード新規・対応履歴追記をブラウザに蓄積し、実OMナビスキーマ互換のCSVでダウンロード（RPA転記用）
- 全データは `data.js` に **AES-256-GCM で暗号化**して格納。パスワード入力でブラウザ内復号（平文はリポジトリに含まれない）

## データ更新（毎朝の運用）

1. 実OMナビからダウンロードしたCSVを `OMナビデータ活用` フォルダの所定の場所に置く
2. `OMナビデータ活用\データ更新.bat` をダブルクリック
   （取込 → JSON書き出し → 暗号化 → GitHubへpush まで自動）
3. 1〜2分後に公開サイトに反映

## 入力→RPA転記の流れ

日中「今日の入力」で蓄積 → CSVダウンロード → RPAが実OMナビへ転記（別途構築） → 翌朝のデータ更新で正式データとして反映。
